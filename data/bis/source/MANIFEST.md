## Extraction notes
- File 05: the source page contains the product table twice; the more complete copy of each row was kept (757 rows: 639 numbered plus unnumbered de-notified/withdrawn entries). The merged QCO cell was expanded onto each row as `Qnnn <QCO name>`; the full notification text is in the appendix of the file.
- File 14: the Remarks column (suspension history) was dropped; some listed labs may be suspended, so check the source PDF for operative status.
- File 17 is the 2018 text; BIS amended it repeatedly (2020-2026). Amendment PDFs are listed at https://www.bis.gov.in/the-bureau/bis-act-rules-and-regulations/?lang=en and were not merged. The FAQ in file 01 already states some current values (for example licence initially up to two years).
- Some numbers differ between official pages (for example the consumer hallmark test fee: the general FAQ says Rs 200 by fire assay; the consumer guidelines say Rs 45 per article with Rs 200 minimum per lot). Both are in the KB; cite the page.
- File 01 says "Fee amounts ... are in file 17": file 17 holds the Scheme-I fee paragraph (application, renewal and annual licence fee Rs 1000 each; Rs 7,000 per day inspection).
